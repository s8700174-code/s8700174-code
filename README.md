## Featured work

**[Didban](https://github.com/s8700174-code/didban-dashboard)** — an independent Persian executive-dashboard demo. Coordinated analytics, searchable project tracking, browser-only bookmarks, CSV exports, light/dark themes and a responsive RTL interface. Built with JavaScript modules, semantic HTML, CSS and SVG; includes reproducible data-model tests.

**All companies, projects and financial figures are synthetic. This is an independent front-end demonstration, not a previous client delivery or a production system.**

**[Vazhe](https://github.com/s8700174-code/vazhe-persian-transcriber)** — a local-first Persian speech transcription application built with Python and FastAPI, with Whisper-based engines, subtitle output and an optional cloud transcription path requiring explicit consent. Model weights and audio recordings are excluded. The publication passed 14 unit tests.

**[PodStudio](https://github.com/s8700174-code/podstudio)** — an Electron presentation and recording studio with a synchronized teleprompter, source cues and portrait/landscape output. The public source edition includes a neutral demo and passed 25 deterministic tests; real-device recording requires environment-specific validation.

**[Moallemyar](https://github.com/s8700174-code/moallemyar-lms)** — a Persian WordPress learning portal integrating H5P, teacher/parent learner roles, course progression and reports, with a companion theme. Published as pilot source code with syntax checks; real SMS and deployment acceptance remain environment-specific.
